# Repository Guidelines & Rules

## MCP Server Management

- Whenever any MCP server is added, modified, or removed in [mcp-config/mcp_config.json](file:///c:/Users/Dell/Documents/GitHub/ai-toolkit/mcp-config/mcp_config.json):
  - **Always update the table** in [mcp-config/README.md](file:///c:/Users/Dell/Documents/GitHub/ai-toolkit/mcp-config/README.md) to reflect the server name, package, purpose, and required configuration/env variables.
  - **Do not include raw JSON code blocks** in `mcp-config/README.md`. Keep the README clean with the summary table and reference `mcp_config.json` for configurations.
